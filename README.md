# whisper-finetuning

Репозиторий состоит из трёх файлов формата .ipynb с кодом. 

Первый файл - "сравнительный анализ моделей + настройка гиперпараметров.ipynb" - содержит сопоставление перформансов моделей Whisper и SpeechRecognition(Google) на небольших пробных выборках, а также процесс подбора наилучших значений гиперпараметров для модели Whisper.

Следующие два файла - "whisper_small_fine_tuning_actions.ipynb" и "whisper_small_fine_tuning_objects.ipynb" - содержат подсчёт бенчмарков и дообучение Whisper размера small для записей с действиями и объектами соответственно.
